Nebula v1.0.0 是首个正式版本 —— 一个用统一界面管理云对象存储的跨平台桌面应用,基于 **Rust + Tauri** 打造,原生、轻量。首发接入**阿里云 OSS**,后续厂商只需实现一个 `StorageProvider` 接口即可加入,界面无需改动。

- **版本号**:v1.0.0
- **发布日期**:2026 年 7 月 7 日
- **平台**:macOS(Universal)· Windows(x64)· Linux(x86_64)

## 账号与安全

- 多账号管理:增、删、改、切换
- 账号元信息存本地 **SQLite**,AccessKeySecret 存**系统钥匙串**(macOS Keychain / Windows Credential / Linux keyutils)
- 应用设置(分享链接有效期、传输并发数)持久化到 SQLite

## 浏览

- 桶 / 目录逐层展开(基于 OSS delimiter)
- **列表 / 网格**两种视图,网格带图片缩略图
- 按名称过滤、按名称 / 大小 / 时间排序
- 图片与视频**在线预览**、对象详情抽屉、底部状态栏统计

## 上传

- **拖拽**文件或整个**文件夹(递归)**、多选文件、选择文件夹上传
- 大文件**自动分片**上传
- 传输面板:多任务**并发**、每任务独立进度、失败**可重试**

## 下载

- **流式**下载,大文件不占内存
- 多选**批量下载**到指定目录

## 文件操作

- 重命名、复制 / 移动到(**级联目录选择器**)、拖拽移动到目录
- 新建文件夹、删除(单个 / 批量,含确认)
- **预签名分享链接**,有效期可配置,一键复制

## 体验

- 明暗**主题**切换、**键盘快捷键**、**右键上下文菜单**
