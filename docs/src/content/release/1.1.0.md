The headline of Nebula 1.1.0 is our **second cloud**: **Huawei Cloud OBS** now ships as a hand-written, standalone Rust SDK, verified end-to-end against a real account and served through the exact same browse / upload / download / share / transfer flow as Alibaba Cloud OSS — a new cloud, with zero UI changes. This release also polishes the desktop **app menu, About dialog, sidebar**, and the **light theme**.

## 华为云 OBS | Huawei Cloud OBS

- 对象读写、桶管理、目录逐层浏览、大文件自动分片上传、预签名分享全部就绪。
- 底层是独立可发布的 `huawei-obs` Rust SDK,不依赖任何聚合库;经真实账号跑通全链路。
- 与阿里云 OSS 共用统一抽象层,新增账号时在云厂商中选择「华为云 OBS」即可。

Huawei Cloud OBS supports object read/write, bucket management, level-by-level browsing, automatic multipart upload for large files, and pre-signed sharing. It is backed by the standalone `huawei-obs` Rust SDK (no aggregation library) and verified against a real account. Pick "华为云 OBS" when adding an account to start using it.

## 桌面体验 | Desktop Experience

- 用 Nebula / 账号 / 编辑 / 视图 的**自定义原生菜单**替代系统默认菜单,常用操作均带快捷键。
- **自定义「关于」弹窗**替代系统默认关于面板,带 logo 与版本信息。
- 侧栏每个账号显示所属云的**品牌色图标**,一眼区分;侧栏与内容区之间可**拖拽调整宽度**,并记忆保留。
- 禁用了 webview 默认右键菜单,右键文件不再误选中文字。

The default menu is replaced with a custom native menu (Nebula / Accounts / Edit / View) with shortcuts, and the system About panel with a custom About dialog. Each sidebar account now shows a brand-colored cloud icon, the sidebar is drag-resizable with its width remembered, and the default webview right-click menu is disabled so right-clicking no longer selects text.

## 界面与主题修复 | UI & Theme Fixes

- 修复**浅色主题**下按钮 hover 变深、表格行分隔线偏重、报错文字过浅看不清等问题。
- 账号列表条目增加间距,hover 高亮不再上下相贴。

Fixed several light-theme issues (button hover turning dark, heavy row separators, low-contrast error text) and added spacing between sidebar account rows so hover highlights no longer touch.

## 官网与其它 | Website & Misc

- 修复官网深层页面(如博客详情)资源加载失败、站点图标缺失、自定义域名丢失的问题。
- 新增技术博客《手写华为云 OBS SDK 的签名坑》。
- 许可证调整为 **MIT**。

Fixed the website so deep pages (e.g. blog posts) load their assets, the favicon shows, and the custom domain persists; added a technical blog post on the Huawei OBS signature gotchas; relicensed to MIT.
