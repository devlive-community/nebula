Nebula 1.0.0 来了 —— 一个用统一界面管理云对象存储的跨平台桌面应用,基于 **Rust + Tauri**,原生、轻量、开箱即用。首个版本先把**阿里云 OSS** 打磨到"日常够用":从浏览到上传下载、分享、传输管理,一站搞定。后续厂商只需实现一个 `StorageProvider` 接口即可加入,界面无需改动。

## 几个你会喜欢的点

- **像本地文件管理器一样管云** —— 目录逐层浏览,列表 / 网格两种视图,图片视频在线预览,排序、过滤、详情一应俱全。
- **传大文件不再心累** —— 拖拽文件或整个文件夹上传,大文件自动分片;多任务并发、失败可重试,进度尽在眼前。
- **随手分享** —— 一键生成预签名临时链接,有效期自定,复制即走。
- **凭证放心存** —— AccessKeySecret 进系统钥匙串,账号与设置存本地 SQLite。

## 完整能力

| 分类 | 能力 |
|------|------|
| 账号 | 多账号增删改切换;密钥进钥匙串,元信息与设置进 SQLite |
| 浏览 | 目录逐层展开、列表 / 网格视图、排序、过滤、图片视频预览、详情抽屉、状态栏统计 |
| 上传 | 拖拽文件 / 文件夹(递归)、多选、自动分片、进度、并发、失败重试 |
| 下载 | 流式下载(不占内存)、批量下载到指定目录 |
| 文件操作 | 重命名、复制 / 移动(级联选择器 / 拖拽)、新建文件夹、删除(单个 / 批量) |
| 分享 | 预签名临时链接,有效期可配置 |
| 体验 | 明暗主题、键盘快捷键、右键上下文菜单 |
