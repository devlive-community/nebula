# Nebula

**マルチクラウドのオブジェクトストレージを管理するクロスプラットフォームのデスクトップアプリ** —— Aliyun OSS、Tencent COS、Huawei OBS、AWS S3、Cloudflare R2、Qiniu Kodo、MinIO、Backblaze B2、Wasabi、DigitalOcean Spaces を、ローカルのファイルマネージャーのように 1 つのネイティブアプリから管理:閲覧、アップロード / ダウンロード、共有、クラウド間の移行まで一括で。

Rust + Tauri 製 —— 軽量・高速で、macOS / Windows / Linux でネイティブ動作。各クラウドは、集約ライブラリに依存しない手書きの独立公開可能な Rust SDK で実装されています。

>

## 対応クラウド

| プロバイダー | 状態 | 署名 |
|--------------|------|------|
| Aliyun OSS | ✅ 実アカウントで検証済み | V2 (HMAC-SHA1) |
| Huawei OBS | ✅ 実アカウントで検証済み | V2 (HMAC-SHA1) |
| Tencent COS | ✅ | 独自の q-sign |
| Qiniu Kodo | ✅ | S3 互換(`s3-core` を共用) |
| AWS S3 | ✅ | SigV4 |
| Cloudflare R2 | ✅ | S3 互換(SigV4) |
| MinIO | ✅ | S3 互換(http / カスタムポート対応) |
| Backblaze B2 | ✅ | S3 互換(`s3-core` を共用) |
| Wasabi | ✅ | S3 互換(`s3-core` を共用) |
| DigitalOcean Spaces | ✅ | S3 互換(専用コンストラクタで endpoint から region を推定) |

> プロバイダー追加 = `<vendor>` SDK を 1 つ書き(S3 互換なら `s3-core` を再利用)、provider アダプターを 1 つ用意して `app-core` に登録するだけ —— **UI の変更は不要**。

## 機能

- **閲覧とプレビュー** —— フォルダーの階層展開、リスト / グリッド表示、並べ替えとフィルター;画像 / 動画 / 音声 / PDF / テキスト・コードのプレビュー;オブジェクト詳細にストレージクラス、実際の Content-Type(編集可)、読み書き可能なオブジェクトタグを表示;フォルダー / バケットのサイズ統計とストレージクラス別の内訳。
- **アップロードとダウンロード** —— ファイルやフォルダーのドラッグ、複数選択;大容量ファイルの並列マルチパートと再開;内容が変わらないファイルは即スキップ;メモリを消費しないストリーミングダウンロード、フォルダー丸ごとの再帰ダウンロード。
- **移行と整理** —— オブジェクトやフォルダーをアカウント間・クラウド間で移行(同一アカウントはサーバーサイドコピー、アカウント間は自動中継);同一アカウント内で任意のディレクトリへコピー / 移動 / リネーム;選択オブジェクトの**一括リネーム**(接頭辞 / 接尾辞 / 検索置換、適用前にプレビュー)。
- **共有と公開** —— 署名付きのダウンロード / アップロードリンクを生成;オブジェクトを公開読み取りにして**期限のない直リンク**を取得、アカウントごとに独自ドメイン / CDN も設定可能。
- **検索とバッチ** —— バケット内の再帰検索(名前 / サイズ / 種類でフィルター)、結果を複数選択してストレージクラス変更 / 復元 / 削除 / ダウンロード;別リージョンのバケットは自動的に各リージョンへルーティング。
- **ナビゲーションと効率** —— **Cmd/Ctrl+K コマンドパレット**(入力してアカウント / ブックマークへジャンプ、またはコマンド実行)、**ブックマーク**、**最近アクセスした場所**;日本語を含む多言語 UI、ダーク / ライトテーマ、ショートカット、コンテキストメニュー。
- **転送管理** —— 並列数の制御、全体の速度制限、速度 / 残り時間、キャンセル / 再開、再起動後の復元、失敗分の一括リトライ。
- **ストレージの整理** —— 中断で残った未完了のマルチパートアップロードを一括クリーンアップして、無駄に課金される容量を回収;単一オブジェクトやフォルダー全体のストレージ階層変更・アーカイブ復元。
- **アカウントとセキュリティ** —— 認証情報はシステムキーチェーンに保存;メタ情報・設定・ブックマーク・最近の場所・UI 設定はローカル SQLite に永続化(テーブル分割、未完了の転送は再起動後も再開可能)。
- **自動更新** —— アプリ内で新バージョンを検出し、更新署名を検証してワンクリックでインストール。

## アーキテクチャと開発

Rust + Tauri 2.0、厳密に一方向の 3 層アーキテクチャを持つモノレポ:`cloud-core → ベンダー別 SDK → provider アダプター → app`。認証情報はシステムキーチェーン、非同期は tokio。

ディレクトリ構成、SDK プレイブック、ベンダー別の仕様書は [メイン README(简体中文)](README.zh-CN.md) と [`docs/`](./docs) を参照。アプリの実行とパッケージング:[app/README.md](./app/README.md)。
