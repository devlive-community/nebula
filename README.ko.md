# Nebula

**멀티 클라우드 오브젝트 스토리지를 위한 크로스 플랫폼 데스크톱 관리자** —— Aliyun OSS, Tencent COS, Huawei OBS, AWS S3, Cloudflare R2, Qiniu Kodo, MinIO를 로컬 파일 관리자처럼 하나의 네이티브 앱에서 관리합니다: 탐색, 업로드 / 다운로드, 공유, 클라우드 간 마이그레이션까지 한 곳에서.

Rust + Tauri로 제작 —— 가볍고 빠르며 macOS / Windows / Linux에서 네이티브로 동작합니다. 각 클라우드는 집계 라이브러리에 의존하지 않고 직접 작성한 독립 배포 가능한 Rust SDK로 구현되어 있습니다.

> 웹사이트: <https://nebula.devlive.org/> · 다운로드: [GitHub Releases](https://github.com/devlive-community/nebula/releases)

## 지원 클라우드

| 제공업체 | 상태 | 서명 |
|----------|------|------|
| Aliyun OSS | ✅ 실제 계정으로 검증 | V2 (HMAC-SHA1) |
| Huawei OBS | ✅ 실제 계정으로 검증 | V2 (HMAC-SHA1) |
| Tencent COS | ✅ | 전용 q-sign |
| Qiniu Kodo | ✅ | S3 호환(`s3-core` 공유) |
| AWS S3 | ✅ | SigV4 |
| Cloudflare R2 | ✅ | S3 호환(SigV4) |
| MinIO | ✅ | S3 호환(http / 사용자 지정 포트) |

> 제공업체 추가 = `<vendor>` SDK 하나 작성(S3 호환은 `s3-core` 재사용) + provider 어댑터 하나 만들어 `app-core`에 등록하면 끝 —— **UI 변경 불필요**.

## 기능

- **탐색 및 미리보기** —— 폴더 단계별 펼치기, 목록 / 그리드 보기, 정렬 및 필터; 이미지 / 동영상 / 오디오 / PDF / 텍스트·코드 미리보기; 오브젝트 상세에 스토리지 클래스, 실제 Content-Type(편집 가능), 읽기/쓰기 가능한 오브젝트 태그 표시; 폴더 / 버킷 크기 통계와 스토리지 클래스별 분포.
- **업로드 및 다운로드** —— 파일이나 폴더 드래그, 다중 선택; 대용량 파일의 병렬 멀티파트 및 이어받기; 변경되지 않은 파일은 즉시 건너뛰기; 메모리를 쓰지 않는 스트리밍 다운로드, 폴더 전체 재귀 다운로드.
- **마이그레이션 및 정리** —— 오브젝트나 폴더 전체를 계정 간·클라우드 간 이동(동일 계정은 서버 측 복사, 계정 간은 자동 중계); 동일 계정 내에서 임의의 디렉터리로 복사 / 이동 / 이름 변경; 선택한 오브젝트의 **일괄 이름 변경**(접두사 / 접미사 / 찾아 바꾸기, 적용 전 미리보기).
- **공유 및 공개** —— 사전 서명된 다운로드 / 업로드 링크 생성; 오브젝트를 공개 읽기로 설정해 **만료 없는 직접 링크** 획득, 계정별 사용자 지정 도메인 / CDN 연결 가능.
- **검색 및 일괄 작업** —— 버킷 내 재귀 검색(이름 / 크기 / 유형 필터), 결과를 다중 선택해 스토리지 클래스 변경 / 복원 / 삭제 / 다운로드; 다른 리전의 버킷은 각 리전으로 자동 라우팅.
- **탐색 및 생산성** —— **Cmd/Ctrl+K 명령 팔레트**(입력하여 계정 / 북마크로 이동하거나 명령 실행), **북마크**, **최근 위치**; 다국어 UI, 라이트 / 다크 테마, 단축키, 컨텍스트 메뉴.
- **전송 관리** —— 동시성 제어, 전역 속도 제한, 속도 / 남은 시간, 취소 / 이어받기, 재시작 복구, 실패 항목 일괄 재시도.
- **스토리지 정리** —— 중단되어 남은 미완료 멀티파트 업로드를 일괄 정리해 몰래 청구되는 용량 회수; 단일 오브젝트나 폴더 전체의 스토리지 계층 전환·아카이브 복원.
- **계정 및 보안** —— 비밀 키는 시스템 키체인에 저장; 메타데이터, 설정, 북마크, 최근 위치, UI 환경설정은 로컬 SQLite에 영속화(테이블 분리, 미완료 전송은 재시작 후 재개 가능).
- **자동 업데이트** —— 앱 내에서 새 버전을 감지하고 업데이트 서명을 검증해 원클릭 설치.

## 아키텍처 및 개발

Rust + Tauri 2.0, 엄격하게 단방향인 3계층 아키텍처의 모노레포: `cloud-core → 벤더별 SDK → provider 어댑터 → app`. 비밀 키는 시스템 키체인에, 비동기는 tokio로.

전체 디렉터리 구조, SDK 플레이북, 벤더별 사양서는 [기본 README(简体中文)](README.md)와 [`docs/`](./docs)를 참고하세요. 앱 실행 및 패키징: [app/README.md](./app/README.md).
